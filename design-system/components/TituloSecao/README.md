# TituloSecao

Abertura de cada seção: um `rotulo` espaçado e o H2 em `titulo-secao`, com UMA palavra em Pinyon Script (`.script`).

A palavra em script é a palavra que carrega o sentimento: "caminho", "leitura", "mês", "consultou", "mesa". A cor vem do fundo:

| Fundo | Rótulo | Título | Script |
| --- | --- | --- | --- |
| `ameixa`, `toalha` | `lavanda` | `pergaminho` | `vela` |
| `nevoa` | `vela-escura` (`.rotulo--vela`) ou `toalha` | `ameixa` | `toalha` |
| `lavanda` | não usa | `ameixa` | `toalha` |

**O que você fornece:** `<p class="rotulo">`, opcional, e `<h2 class="titulo-secao">` com um `<span class="script">`.

- Faça: rótulo descritivo ("Consultas e valores"), título com voz ("Escolha a sua leitura").
- Não faça: duas palavras em script, script em frase inteira ou `vela` como texto sobre `nevoa`.
- Numeração (I, II, III) só onde existe sequência real: no Como funciona, não nos títulos.
