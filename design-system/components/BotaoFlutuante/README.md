# BotaoFlutuante

Círculo `vela` de 58px, fixo no canto inferior direito, que abre a conversa de agendamento em qualquer ponto da página.

**O que você fornece:** um `<a class="flutuante">` com `aria-label="Agendar pelo WhatsApp"` e um ícone `<svg>` de 28px. A sombra é `sombra-flutuante`.

- Faça: um por página, com a mesma mensagem do botão "Agendar" do topo.
- Faça: deixe 6rem de espaço no fim do rodapé para ele não cobrir os links.
- Não faça: animar, pulsar ou mostrar contador de notificações.
- O ícone do preview é provisório. No site, troque-o pelo ícone oficial do WhatsApp (veja Iconografia).
